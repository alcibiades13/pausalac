# @pausalac/ui

Reserved for shared component primitives consumed by `apps/app` and `apps/web`
(Button, Input, Select, MoneyDisplay, StatusBadge, etc. — see master prompt
§51 and §89, and `docs/implementation-plan.md`).

Deliberately empty at the Phase 1a bootstrap stage — component work starts in
Phase 1b once the design system pass happens. Only `packages/config` (design
tokens) is consumed by the frontends today.
